# NTI SystemVerilog

This repository contains my work completed during the **NTI Digital IC Design Training**.

## Repository Structure

### 📁 NTI_sv_F_project

Final verification project for the SystemVerilog course.

- 16-bit ALU Design (Provided)
- Self-checking Testbench
- Verification Environment
- Simulation Results
- Project Documentation

### 📁 lab6

SystemVerilog programming exercises that focus on arrays and built-in array methods.

Implemented Tasks:

- Separate even and odd numbers
- Find the longest consecutive sequence
- Find the second maximum value
- Count frequency of each element using associative arrays

Simulation screenshots are included.
